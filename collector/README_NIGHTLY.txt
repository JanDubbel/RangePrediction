RangePrediction / LOWTRAN 7 — ночной сборщик v2 (исправленная геометрия)
=====================================================================

ВАЖНО: это версия для ПОДГОТОВКИ нового массива данных. Полный расчёт
не запускается автоматически. Нужен явный параметр --full.

В ZIP находятся:
  lowtran_overnight_atlas.py   — генератор и экспорт результатов
  lowtran/                     — Python LOWTRAN 7 с исправлением BETA
  lowtran/_tables.bin          — обязательные таблицы LOWTRAN
  start_night.bat/.sh          — ручной запуск полного расчёта
  run_smoke.bat/.sh            — быстрая проверка 9 точек
  tests/                       — локальные тесты генератора
  LOWTRAN_LICENSE.txt         — лицензия/авторство исходного порта

Нужны: Python >=3.10 и NumPy >=2; Fortran не нужен.

ИСПОЛЬЗОВАНИЕ ИЗ РЕПОЗИТОРИЯ GITHUB:
  Для RangePrediction/collector/ требуется соседняя папка RangePrediction/python/;
  библиотека автоматически будет взята из ../python/lowtran/.
  В автономном ZIP библиотека lowtran/ уже включена рядом со сборщиком.

  python -m pip install "numpy>=2"

ПРОВЕРКА ПЕРЕД ЗАПУСКОМ:
  python lowtran_overnight_atlas.py --plan
  python lowtran_overnight_atlas.py --preflight
  python lowtran_overnight_atlas.py --smoke

--plan не считает спектры и показывает число запланированных точек.
--preflight вычисляет 4 контрольные короткие трассы (без записи базы).
--smoke вычисляет 9 контрольных точек и создаёт отдельную базу/CSV/ZIP в
  папке lowtran_atlas_corrected_smoke.
Ожидаемая проверка: 9 успешных точек, 0 ошибок.

ПОЛНЫЙ РАСЧЁТ (только когда владелец проекта решит запускать):
  python lowtran_overnight_atlas.py --full

Либо запустить start_night.bat (Windows) или start_night.sh (Linux).
Это создаст НОВУЮ папку lowtran_atlas_corrected_v2. Старую базу атласа
не трогать и не подкладывать в эту папку! Сборщик проверяет SHA256 ядра
и откажется продолжать базу от другой версии расчёта.

ВОЗОБНОВЛЕНИЕ ПОСЛЕ ПАУЗЫ:
  python lowtran_overnight_atlas.py --full

Просмотр прогресса без расчётов:
  python lowtran_overnight_atlas.py --status

Экспорт текущих результатов без вычислений:
  python lowtran_overnight_atlas.py --export-only

Если понадобятся дополнительные короткие дальности (можно включить даже
после завершения базовой сетки, уже готовые точки не повторятся):
  python lowtran_overnight_atlas.py --full --dense-short

Базовая сетка ТОЧНО соответствует прошлому прогону:
  78 618 комбинаций; 6 климатов; аэрозоли 1,4,5,6 и 0;
  МДВ: 5,10,15,20,30,50, а также 7,12,25,40 км;
  горизонтальные высоты: 0,0.25,0.5,1,2,3,5 км;
  дополнительные высоты и наклоны в стадии 6;
  дальности: 0.5,0.75,1,1.5,2,2.5,3,4,5,7.5,10,12.5,15,20,
            25,30,40,60,80 км.

Опция --dense-short добавляет ещё 27 330 точек в стадии 7:
  D=1.25,1.75,2.25,2.75,3.25,3.5,4.5 км, где разрешена геометрия.
  Итого с ней 105 948 точек. Для прямого сопоставления со старым массивом
  рекомендуем сначала базовую сетку, затем при желании стадию 7.

Спектральный диапазон: 3–5 мкм, шаг по волновому числу 20 см^-1.
Интегралы: Planck M_lambda при 250,283,300,320 K, а также при 283 K
  веса lambda*M_lambda и M_lambda/lambda.
Спектральная чувствительность приёмника равна единице.
В SQLite сохраняются и спектральные пропускания компонентов LOWTRAN.

Историческое наблюдение: 216 отказов в прошлой базе были только для
  0→0.25 км при D=60 или 80 км (различные сценарии); они связаны с тем,
  что LOWTRAN не вернул спектр. Сборщик v2 сохраняет сведения об отказах,
  не пытается выдать их за нулевое пропускание.

Данные: lowtran_atlas_corrected_v2/lowtran_atlas.sqlite, lowtran_integrals.csv
Архив для передачи: lowtran_atlas_corrected_v2/lowtran_atlas_bundle.zip

Внимание: локальная геометрическая поправка BETA экспериментальная, не
  является полной научной валидацией всех режимов LOWTRAN.
  Ночной прогон НЕ запускался при подготовке этого комплекта.
